Команды для сервера и автоматического деплоя (CLI)

Используйте эти команды в SSH терминале хостинга (Timeweb) или в CI/CD скриптах

Создание полного бэкапа (БД + медиа):

python manage.py backup_data Адаптивное быстрое сжатие + снимок SQLite + фикстуры

Быстрый дамп базы (без медиа):

python manage.py backup_data --quick-db Мгновенный снимок таблиц за долю секунды

Аудит и сравнение с живой БД:

python manage.py restore_data --inspect Сверяет количество записей по каждой модели до восстановления

Чистый деплой на сервере:

python manage.py restore_data --clear --yes Автоматически находит свежий архив, делает точку отката и накатывает данные
